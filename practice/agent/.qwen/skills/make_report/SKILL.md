# Make Report

Создаёт Excel-отчёт по задачам TODO-приложения: сводку метрик и детальный список задач.

## Что делает

1. Получает полный список задач из REST API TODO-приложения по адресу из `--url` или `TODO_API_URL` (GET `{url}/api/tasks`).
2. Считает метрики и создаёт Excel-файл `report.xlsx` (или путь из `--output`) с двумя листами:
   - **«Сводка»** — дата формирования, всего/выполнено/невыполнено, % выполненных (округление до одного знака), просроченные невыполненные, задачи со сроком сегодня и невыполненные, задачи без дедлайна и невыполненные, невыполненные по приоритетам high/normal/low. Для каждой метрики сохранено правило расчёта.
   - **«Задачи»** — столбцы ID, Название, Статус, Приоритет, Дедлайн, Дней до дедлайна, Срок, Примечание. Сортировка: сначала невыполненные, потом выполненные; внутри группы по дате дедлайна (задачи без даты — в конец), затем по ID. Закреплённая строка заголовка и фильтр по столбцам.

## Как использовать

Запустить скрипт из папки `practice/agent`:

```bash
python3 .qwen/skills/make_report/build_report.py --url http://127.0.0.1:5000 --output report.xlsx
```

- Адрес API: аргумент `--url` или переменная окружения `TODO_API_URL` (по умолчанию `http://127.0.0.1:5000`).
- Файл отчёта: аргумент `--output` (по умолчанию `report.xlsx`).
- Опционально: `--date YYYY-MM-DD` — дата формирования отчёта (по умолчанию сегодня, местное время).

## Проверка

После запуска проверь в `report.xlsx`:
- оба листа («Сводка» и «Задачи») присутствуют;
- количество задач на листе «Задачи» совпадает со значением «Всего задач» на «Сводке»;
- метрики на «Сводке» соответствуют содержимому задач на листе «Задачи»;
- на листе «Задачи» закреплена строка заголовка и включён фильтр.

## Заметки

- Данные задач не изменяются — скрипт только читает API.
- «Просрочена» присваивается только невыполненной задаче с дедлайном раньше даты формирования отчёта; выполненным задачам ставится срок «не задан».
- Приоритеты: `high`, `normal`, `low`; прочие значения учитываются в метрике «Невыполненные (прочие)».
- Тесты: `python3 .qwen/skills/make_report/test_build_report.py` (unittest; дата фиксирована, чтобы результаты не зависели от дня запуска).
